Introduction

Hi, I'm Dhruv Dhayal — a Software Engineer who learns by building real systems, breaking them, and fixing them properly.

I work primarily with Java Springboot and Docker, building backend systems around authentication, payments, APIs, concurrency, and asynchronous workflows. My projects focus on understanding the engineering problems behind a system — from race conditions and idempotency and database architecture.

I also write technical case studies and build personal tools to explore ideas in practice. Currently, I'm deepening my understanding of Generative AI and how it can be applied to the systems I build.

What I Work On
  • Authentication & Security OAuth, JWTs, secure sessions, and reusable authentication infrastructure.
  • Reliable Transactions Payments, idempotency, concurrency control, and race-condition handling.
  • Asynchronous Systems Event-driven workflows, background jobs, retries, and failure recovery.
  • Backend Architecture API design, database architecture, object storage, and system evolution.

My approach: understand the root cause, design clear architecture, implement with proper observability.
